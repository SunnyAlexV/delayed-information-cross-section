================================================================================================
lab69  -  THE SUBSTITUTION RATE UNDER FOUR VOLATILITY PROXIES
================================================================================================
  The paper measures volatility one way and never varies it.  2 of
  these arms remove the overnight term entirely, which is the term
  that spans the foreign trading sessions the substitute block is
  built from, and so the term through which the published design
  cannot separate information from measurement.

  YZ done  (the published estimator; 4,862 test days)
  CC done  (close-to-close; no open, high or low; 4,862 test days)
  RS done  (Rogers-Satchell; intraday only, no overnight; 4,862 test days)
  PK done  (Parkinson; intraday only, no overnight; 4,862 test days)

================================================================================================
A.  THE BENCHMARK ITSELF, BEFORE ANY RATE IS READ
================================================================================================
  S_own(0) is how well the domestic model forecasts its own target
  with nothing withheld.  It is the denominator's anchor, and if it
  moves a lot between proxies the rates are not comparable.

  proxy     S_own(0)   what it is built from
  YZ          0.4988   the published estimator
  CC          0.2833   close-to-close; no open, high or low
  RS          0.4467   Rogers-Satchell; intraday only, no overnight
  PK          0.5258   Parkinson; intraday only, no overnight

VERDICT
================================================================================================
  Published estimator at eleven weeks:            71.5%
  Without the overnight term (RS, PK):           69.4%, 70.1%
  Close-to-close only, no OHLC at all:           73.4%
  Largest fall from the published figure:        +2.0 points

  The rate does not depend on the overnight term.  The two arms
  that remove it entirely return a rate within ten points of the
  published one, so the foreign cross-section is not merely
  predicting a measurement of the foreign sessions themselves.
  The explanation this file was written to test is ruled out at
  the size the test can resolve.

  Either way this is one measurement varied, not a proof that the
  target is well measured.  No intraday data is used anywhere in
  this repository, and a realised-variance target built from
  five-minute returns would be a better object than any of the four.
