================================================================================================
0.  DOES THE FILTER RECOVER A STATE IT IS GIVEN?
================================================================================================
Simulate the model the filter assumes, hide the first series for the last
`delta` days, and see how well the filtered state tracks the truth.  With
nothing hidden it should be near-perfect; the fall-off as days are hidden
is the quantity the whole exercise turns on.

  true phi 0.970 -> estimated 0.912
  days hidden    corr(filtered, true)
  (measured on one FIXED 400-day window for every row.  A first version
   averaged over the whole block, where hiding one of eight series at the
   end moved nothing; a second used a window that grew with the number of
   days hidden, so the rows were not comparable with each other.)

            0                  0.9855
            1                  0.9848
            5                  0.9846
           21                  0.9846
           55                  0.9846

  hiding the target for 55 days costs 0.0009 of correlation.
  That is not a null result, it is the mechanism.  Seven other series
  load on the same factor, so removing one of eight measurements barely
  moves the state estimate however long it is hidden.  Whether the real
  cross-section behaves like that is what part A tests - here it is only
  established that the filter behaves as its own assumptions imply.
